# Brazilian E-Commerce Data Analysis (SQL)

## Project Overview
This project focuses on exploring and analyzing the Brazilian E-Commerce Public Dataset by Olist using SQL and Python.

The objective is to understand the dataset, explore e-commerce operations, and extract meaningful business insights through data analysis.

## Dataset
- **Source:** Olist Brazilian E-Commerce Public Dataset
- **Database:** MySQL
- **Tables:** 9
- **Records:** Approximately 1.55 million across all tables

## Tools & Technologies
- MySQL
- MySQL Workbench
- Python
- Pandas
- Git & GitHub
